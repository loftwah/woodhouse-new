## Meaning and review

- Failure loop: six-stage forward work with an actual returning evidence circuit. The FT/Fighter public historical example says geometry passed while design missed; independent visual review became a separate check. Its browser-viewport illustration is explicitly an illustrative diagnostic, not a product screenshot. Root reviewed this selected pair for meaning and phone readability.
- Lineage: six working practices from composition to factory operation. No dates are invented for transitions. Root and an independent critic rejected wide v2's generic icon presentation. Wide v4 replaces it with input/output interface contracts; human-intent and agent-change annotations on a shared change; a Scope/Owner/Limit brief bounding code; competing diffs with an independent review witness; exact-candidate revision/gate fields; and intent/work/evidence records tied to one revision. All are explicitly illustrative work artefacts, with no invented code, hash, gate command or passed result. The wide continuation joins the two levels without a false return loop. Phone v4 remains an artwork study after root superseded bitmap phone publication.
- Pirates: source-backed rules, reconstruction and whole-game parity precede a labelled locked Gate B. Unknowns stay unknown. Root rejected phone v2 because its source-gap branch appeared after the locked gate and a conditional tail continued below the seam. Phone v3 branches the source gap from Original evidence and terminates at STOP; the main path ends at Gate B. The future expansion condition is disconnected text, with no crossing line or arrow. It expressly requires integrated parity and the owning gate's acceptance.
- Project network: ten named independent projects receive bounded agent work from common scope. Projects do not link to one another. Each owns identity, source, data and release gates. Markers establish neither activity nor health. Coral was removed from project markers to avoid implying stops.

The selected phone editions were downsampled to 350px for inspection; corresponding `*-350px-qa.png` files are retained beside the candidates. These downscales are QA artefacts, not new artwork or selected masters. Main labels, explanatory text and necessary limits were read at that size. Source footers remain compact notation.

The generated ink has minor tonal variation. Root instructed no further near-ink or nonmaterial concept-mark polishing. All software artefacts are conceptual linework; no game UI, code, version, check result or private payload was fabricated as evidence. No production, physical-device, adoption or MP acceptance claim follows from these images.
